Hypixel SkyBlock Item Generator

A lightweight, browser-based Hypixel SkyBlock item generator for creating custom item definitions and generating Java source code from them.

The project is built with HTML, CSS, and JavaScript, making it simple to run locally or deploy as a static website.

«Unofficial community project. This tool is not affiliated with or endorsed by Hypixel or Mojang.»

---

✨ Features

- 🧱 Create custom Hypixel SkyBlock item definitions
- 🏷️ Set item names, categories, rarities, lore, and URLs
- ⚔️ Configure different item types
- 📊 Add custom item statistics:
  - Strength
  - Crit Chance
  - Crit Damage
  - Intelligence
  - Health
  - Defence
  - Ferocity
  - Speed
  - Magic Find
- ☕ Generate Java source code from your configuration
- 📋 Copy generated code directly to your clipboard
- 📱 Responsive interface
- 🚀 No backend or database required
- 🌐 Runs entirely in the browser

🚀 Getting Started

1. Clone the repository

git clone https://github.com/feloony/Hypixel-Item-Generator.git
cd Hypixel-Item-Generator

2. Run the generator

No build system or package installation is required.

Simply open:

index.html

in a modern web browser.

You can also deploy the project to any static hosting provider.

🧩 How It Works

1. Enter an item name.
2. Select the item category and rarity.
3. Add optional lore and a URL.
4. Configure the item type when needed.
5. Enter the item's statistics.
6. Click Generate Java Class.
7. Review the generated Java source code.
8. Click Copy to Clipboard to copy the result.
